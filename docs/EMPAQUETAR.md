# Empaquetar y ejecutar

Proyecto principal gestion-equipos → Maven Build → Goals: package, Profiles vacío para generar la entrega.

Para iniciar desde Maven Build: Goals package, Profiles iniciar y MONGODB_URI en Environment. Ejecuta solamente esta configuración.

JAR completo: gestion-unificada/target/gestion-unificada-1.0.0.jar. Ambas interfaces usan 8092: / para REST y /inicio para MVC.

Consulta README.md para importación y conservación de datos H2.
